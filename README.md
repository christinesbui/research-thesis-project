# research-thesis-project
As a Graduate Research Assistant, I worked on a Phase 2 clinical trial regarding focal hand dystonia, performing descriptive statistics, exploratory data analysis, normality, mixed effects models, and paired t-tests. The overall goal is to assess treatment efficacy at different timepoints of the study. 

This repository includes my final thesis presentation of the work I've done on this project, the code (done in R), and my final report. You can view my code in the QMD file! 

Enjoy looking through the work I've done!
